node-exporter is deployed as a DaemonSet (one pod per node).

  Namespace : {{ .Release.Namespace }}
  Port      : {{ .Values.service.port }}
  Metrics   : node-exporter.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}/metrics

Key metrics consumed by Stage 2 RCA — Infrastructure Level Graph (Graph 2):
  node_cpu_seconds_total                 per-CPU mode breakdown (user, system, iowait)
  node_memory_MemAvailable_bytes         available memory
  node_memory_MemTotal_bytes             total memory (for utilisation ratio)
  node_disk_io_time_seconds_total        disk saturation
  node_network_receive_bytes_total       inbound network traffic
  node_network_transmit_bytes_total      outbound network traffic
  node_filesystem_avail_bytes            free disk space

Prometheus scrapes node-exporter via kubernetes_sd (endpoints role in {{ .Release.Namespace }}).
See prometheus/values.yaml extraScrapeConfigs.
